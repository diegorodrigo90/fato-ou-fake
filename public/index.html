                  Como jogar

                  1. Leia a carta. É uma afirmação que circulou por aí.
                  2. Arraste para a direita se for fato, para a esquerda se for fake. Ou use os botões.
                  3. Confira a checagem. Cada resposta vem com as fontes para você ver com seus próprios olhos. Arraste a carta para qualquer lado para ver a próxima.
                  4. Ganhe pontos. Acertos seguidos valem mais. Cartas raras e épicas têm mais fontes e dão bônus.
                  5. Volte todo dia. A rodada do dia tem 10 cartas e vale conquistas.

                  Como escolhemos as fontes

                  Nenhuma fonte é neutra por definição. Por isso só entram checagens de verificadores que seguem um código público de princípios (apartidarismo, transparência de fontes, de financiamento e de método) e dados de órgãos oficiais. Toda carta mostra a fonte, com o link para você conferir.
